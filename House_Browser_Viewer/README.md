# Перегляд будинку без Blender

Відкрийте House_Viewer.html у Chrome або Edge. Це один самодостатній файл: можна переслати його іншій людині, він працює без інтернету та сервера. Перемикайте поверхи, кімнати, вигляд згори та обертайте модель. Кнопка «Рендери кімнат» показує фінальні матеріали й освітлення.

Файли House_Floor_1.glb та House_Floor_2.glb можна відкривати окремо в сумісному 3D-переглядачі. Модель для браузера має спрощену геометрію та матеріали; повна редагована версія збережена в House_Library_Design.blend.

Проєкт не завантажений у зовнішні сервіси. Автори бібліотечних моделей і матеріалів перелічені в ASSET_CREDITS.md. Код перегляду використовує Three.js 0.180.0, MIT; ліцензія в THREE_LICENSE.txt.
