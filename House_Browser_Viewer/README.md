# Перегляд будинку без Blender

Відкрийте House_Viewer.html у Chrome або Edge. Це один самодостатній файл: можна переслати його іншій людині, він працює без інтернету та сервера. Перемикайте поверхи й кімнати та обертайте модель. Кнопка «Рендери кімнат» показує фінальні матеріали й освітлення. У локальній редакції 22 нижні двері кухні та пральні відчиняються до прихожої у задані боки; вимикачі перенесені за уточненими скриншотами, а точки розеток і вимикача дитячої відновлені/скориговані.

Кнопка «Прогулянка по будинку» вмикає перегляд від першої особи. Рухайтеся клавішами W/A/S/D або стрілками, повертайте погляд мишею, Shift сповільнює рух. Клацніть у 3D-сцені для керування мишею; Esc повертає курсор, а кнопка режиму — до звичайного огляду. Можна пройти між поверхами сходами.

Кнопка «Режим електрика» працює і в огляді, і під час прогулянки. Вона прибирає меблі й декор та залишає стіни, перегородки, двері, підлоги, стелі, електроточки й стаціонарні світильники. Дві настільні лампи кабінету, що підключаються до розеток, у цьому режимі приховані. Щоб повернути звичайний вигляд, натисніть кнопку ще раз. Усі точки електрики показані як попередні пропозиції, не як виконавча схема.

Файли House_Floor_1.glb та House_Floor_2.glb можна відкривати окремо в сумісному 3D-переглядачі. Модель для браузера має спрощену геометрію та матеріали; повна редагована версія збережена в House_Library_Design.blend.

Модель не завантажується на сторонні 3D-сервіси; публічний переглядач розміщується через GitHub Pages. Автори бібліотечних моделей і матеріалів перелічені в ASSET_CREDITS.md. Код перегляду використовує Three.js 0.180.0, MIT; ліцензія в THREE_LICENSE.txt.
