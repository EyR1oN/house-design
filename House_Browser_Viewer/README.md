# Перегляд будинку без Blender

Відкрийте House_Viewer.html у Chrome або Edge. Це один самодостатній файл: можна переслати його іншій людині, він працює без інтернету та сервера. Обидва поверхи завантажуються разом: вибір першого показує тільки перший, а вибір другого складає обидва поверхи один над одним. Між ними показане бетонне перекриття зі стяжкою, яке лишається видимим і в режимі електрика. Кнопка «Рендери кімнат» показує фінальні матеріали й освітлення. Стаціонарні стельові плафони, підвіси, бра та вбудоване світло витяжки залишаються видимими; переносні настільні лампи приховуються.

Кнопка «Прогулянка по будинку» вмикає перегляд від першої особи. Рухайтеся клавішами W/A/S/D або стрілками, повертайте погляд мишею, Shift сповільнює рух. Клацніть у 3D-сцені для керування мишею; Esc повертає курсор, а кнопка режиму — до звичайного огляду. Можна пройти між поверхами сходами.

Кнопка «Режим електрика» працює і в огляді, і під час прогулянки. Вона прибирає меблі й декор та залишає стіни, перегородки, двері, підлоги, стелі, електроточки й стаціонарні світильники, зокрема вбудоване світло витяжки. Дві настільні лампи кабінету, що підключаються до розеток, у цьому режимі приховані. Щоб повернути звичайний вигляд, натисніть кнопку ще раз. Усі точки електрики показані як попередні пропозиції, не як виконавча схема.

У спальні дві пари «розетка + вимикач» вирівняні над тумбочками з обох боків ліжка: розетки на висоті 0,68 м, вимикачі — 0,82 м від чистої підлоги.

Файли House_Floor_1.glb та House_Floor_2.glb можна відкривати окремо в сумісному 3D-переглядачі. Перед пакуванням вони очищені від вузлів і геометрії, які не належать активним сценам. Модель для браузера має спрощену геометрію та матеріали; повна редагована версія збережена в House_Library_Design.blend.

Модель не завантажується на сторонні 3D-сервіси; публічний переглядач розміщується через GitHub Pages. Автори бібліотечних моделей і матеріалів перелічені в ASSET_CREDITS.md. Код перегляду використовує Three.js 0.180.0, MIT; ліцензія в THREE_LICENSE.txt.
