# Будинок — окрема версія з готовими меблями

Відкрийте **House_Library_Design.blend** у Blender 4.5 або новішому. Старий проєкт не перезаписано: резервна копія лежить поруч у папці House_Intermediate_Backup_2026-09-30.

## Огляд

У списку View Layer праворуч угорі виберіть **Ground_Design** або **Upper_Design**. Колесо миші — наближення, середня кнопка — обертання, Shift + середня кнопка — переміщення. Home показує всю сцену; NumPad 0 — вид із поточної камери. Z → Material Preview показує матеріали. Папка previews містить готові зображення кімнат і плани поверхів.

## Що входить

Окремий дизайн правої секції на основі збереженої архітектурної моделі: 43 типи готових моделей, 91 розміщення. Меблі, м'які меблі, текстиль, техніка, сантехніка, світильники й декор завантажені з безкоштовної бібліотеки BlenderKit. Покриття використовують текстури Poly Haven. Моделі підготовлено без залежних скелетів, драйверів і сторонніх скриптів.

Збережено Г-подібну кухню з цілісною стільницею, мийкою під вікном, посудомийкою між мийкою й плитою та мікрохвильовкою над духовкою. Передбачена посудомийка 45 см; між плитою та торцевою стіною — 325 мм. Збережено кутовий диван під вікном, телевізійну перегородку перед сходами, вхід у комору, прохід на сходовому майданчику, душ унизу, ванну вгорі, спальню зі зміненим напрямком ліжка та шафою, робочий кабінет із двома столами і чотирма моніторами, принтером і гантелями, П-подібну гардеробну. Остання кімната залишена вільною.

Архітектура, спеціальні корпуси для техніки, безперервна стільниця, перегородки, розетки й вимикачі залишаються індивідуальними елементами будинку. Готові моделі меблів адаптовані до розмірів приміщень; це не специфікація конкретних товарів для закупівлі.

## Бібліотека і перенесення

**Ready_Furniture_Library.blend** — локальна бібліотека моделей. Додайте цю папку у Blender: Edit → Preferences → File Paths → Asset Libraries → +. У вікні Asset Browser виберіть додану бібліотеку; меблі можна перетягувати у сцену. Для точного масштабу орієнтуйтеся на розміри встановлених екземплярів у будинку.

Текстури і креслення запаковані в основний .blend. Його можна відкрити на іншому ноутбуці без інтернету й MCP. Перенесення всієї папки збереже бібліотеку, джерела та скрипти. У assets/prepared збережені стабільні моделі для повторної побудови без завантажень. У data/library_manifest.json наведені автори, посилання та ліцензії; ліцензії на бібліотечні моделі слід зберігати при передачі проєкту. Матеріали Poly Haven — CC0.

## Відтворення

scripts/build_library_design.py повторно будує нову версію з source/House_Intermediate.blend та assets/prepared. scripts/render_library.py створює зображення; scripts/verify_library.py перевіряє геометрію та збереження архітектури. Запуск: blender -b --disable-autoexec --python-exit-code 1 --python scripts/build_library_design.py. Для повторного отримання вихідних моделей є download_library.py; він потребує інтернету, а підготовлені копії для звичайного повторного складання вже додані.

## Інженерні точки

data/electrical_points.json і plumbing_fixture_points.json містять запропоновані точки підключення. Це планувальні координати; фактичні траси, електричні кола та виконані мережі тут не підтверджені. MEP_AS_BUILT не заповнюється припущеннями.
