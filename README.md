# House Design — права секція будинку

Репозиторій: https://github.com/EyR1oN/house-design

Публічний робочий проєкт інтер’єру й архітектурної моделі. У цій робочій гілці — редакція **23**; публічний переглядач оновиться після злиття змін і публікації. Великі файли зберігаються через **Git LFS**.

## Онлайн-перегляд

- **[Відкрити будинок у 3D](https://eyr1on.github.io/house-design/)**
- **[Відкрити PDF-альбом](https://eyr1on.github.io/house-design/house-design.pdf)**
- [Стан автоматичної публікації](https://github.com/EyR1oN/house-design/actions/workflows/publish-house.yml)

Посилання постійні. Після push у main GitHub Actions збирає сайт і PDF з актуальних закомічених GLB та рендерів і публікує GitHub Pages. Не потрібно клонувати репозиторій, встановлювати Blender або входити в GitHub для перегляду. Є звичайний огляд, прогулянка від першої особи та режим електрика. В електричному режимі приховуються меблі й декор, залишаються конструктив будинку, двері, стелі, підлоги, електроточки та стаціонарні світильники; дві настільні лампи кабінету приховуються. Фото підвантажуються окремо; геометрію не спрощено.

PDF містить інтерактивний зміст і всі 36 поточних ракурсів. Кількість сторінок автоматично відповідає gallery_views.json. Дата, редакція та ідентифікатор вихідного коміту дозволяють перевірити актуальність.

Зміни самого .blend треба супроводжувати актуальним експортом і потрібними рендерами. Публікація відхиляється, якщо master змінився, а жоден експорт чи рендер не оновлений. GitHub не відтворює історичні дизайнерські скрипти й не перебудовує будинок заново.

Запис до репозиторію мають власник EyR1oN і запрошений редактор Tatiana2424 після прийняття запрошення. Публічна видимість не надає іншим права push.

## Інший ноутбук

Встановіть Git, Git LFS і Blender 4.5.3 LTS. Клонуйте репозиторій і відкрийте його папку:

```powershell
git clone https://github.com/EyR1oN/house-design.git
cd house-design
```

Потім:

```powershell
git lfs install --local
git lfs pull
```

Переконайтеся, що завантажилися самі великі файли, а не короткі LFS-покажчики. GitHub ZIP не є рекомендованим способом отримання робочої копії з LFS; використовуйте clone.

Перед кожною роботою:

```powershell
git status
git pull --ff-only
git lfs pull
```

Після роботи: зберегти й закрити Blender; оновити потрібні дані, GLB, HTML, рендери та хендоф, потім:

```powershell
git add .
git commit -m "Describe the house update"
git push
```

Працюйте на одному ноутбуці за раз. .blend не зливається як текст; при конфлікті зберігайте обидві версії. Не застосовуйте примусове скидання або force push для синхронізації.

## Контекст і перевірки

Прочитайте `AGENTS.md`, `HOUSE_HANDOFF_UK.md`, `House_Library_Design/README.md` та `Design_Research/PLANNING_CONTEXT_UK.md`. Історичні build/refine-скрипти вже застосовані; не запускайте їх поверх поточного master.

Результати імпорту й перевірок: `MIGRATION_AUDIT_UK.md` та `House_Library_Design/data/import_audit.json`. Перевірка редакції 17 зафіксована в `House_Library_Design/data/revision17_report.json`: верхнє продовження ТВ-стіни прибране, нижня ТВ-стіна й перегородка біля шафи збережені. Перевірка дверей редакції 16: `House_Library_Design/scripts/verify_revision16.py`; її базова таблиця редакції 15 включена у source/, тому повна резервна папка для неї не потрібна.

Blender-програма в Tools/, локальні резервні копії, ZIP, журнали та облікові дані не включаються в Git. Оригінальний переносний ZIP з редакцією 15 і Blender залишився на робочому столі першого ноутбука. Запускач `Відкрити Blender.cmd` підтримує локальну папку Tools/, змінну BLENDER_EXE або Blender у PATH.

Авторство й ліцензії моделей: `House_Library_Design/ASSET_CREDITS.md`. Бібліотечні активи не отримують нову відкриту ліцензію через збереження у цьому репозиторії. Інженерні точки — PROPOSED.


## Безпечна збірка 3D-переглядача

Готовий автономний HTML уже включений у репозиторій; після clone + LFS його можна відразу оглядати. Для повторного пакування з поточних GLB і фото потрібен Python 3.10+; сторонні Python-пакети й інтернет не потрібні:

```powershell
python automation/build_viewer.py
```

Або `Build-Viewer.ps1 -PythonPath <шлях-до-python.exe>`. Для тестової копії без зміни основного переглядача:

```powershell
python automation/build_viewer.py --output .local-preview/House_Viewer.html
```

Збірка читає обидва House_Floor_*.glb, gallery_views.json та відповідні previews/*.png. Дизайн, .blend, геометрію і рендери вона не змінює. Збережені рух кутової шафи, матеріали й керування переглядачем; втрачені LFS-файли зупиняють збірку до заміни результату. Шаблон інтерфейсу: House_Browser_Viewer/viewer_template.html.

У режимі прогулянки W/A/S/D або стрілки переміщують по кімнатах і сходах обох поверхів; миша повертає погляд, Shift сповільнює крок. Клік у сцені захоплює курсор, Esc повертає його, кнопка режиму повертає до звичайного огляду. Перегляд не змінює Blender-модель.

Після заміни меблів у Blender потрібно перевірити їхню геометрію й опору, оновити відповідні дані та рендери, експортувати змінені GLB й лише тоді пакувати HTML. Сам git push не запускає Blender і не оновлює експорт. Для нових експортів зберігати pantry_role й 20 рухомих вузлів кутової шафи; Z другого поверху +3.2 м у Blender відповідає підлозі Y=0 у його окремому GLB.

Старий Rebuild_Library_Design.ps1 тепер навмисно зупиняє виконання: він раніше перебудовував початковий master поверх пізніших редакцій. Історичні build/refine-скрипти доступні як історія, але не є щоденною командою збірки.


## Локальна збірка сайту та PDF

```powershell
python -m pip install -r web/requirements.txt
python automation/build_site.py
python automation/verify_site.py .site-dist
```

Результат у .site-dist/. Це вебверсія з окремими ресурсами, тому відкривайте її через вебсервер або використовуйте опубліковані посилання вище. Для локального відкриття без сервера залишається автономний House_Viewer.html.

Публікація: .github/workflows/publish-house.yml. Інтерфейс і рух кутової шафи збережені з наявного переглядача. Стиснення моделі застосоване лише під час передачі: після розпакування SHA-256 збігається з вихідним GLB. Шрифти PDF DejaVu з ліцензією включені в web/fonts/.
